# Coding

## General

- Don't edit the code that doesn't affect the task you are working on.
- Keep visibility of interfaces, classes, functions, properties minimal.
- In error handling, prefer `kotlin.Result` or custom result types (enums, sealed interfaces, sealed
  classes) to throwing exceptions.

## Kotlin

When writing kotlin code use skills:

- /chrisbanes-skills:kotlin-control-flow
- /chrisbanes-skills:kotlin-api-design

When using kotlin concurrency features, coroutines, suspend functions, Flow, use
/chrisbanes-skills:kotlin-concurrency-and-flow skill.

## Compose

When writing compose code always use skills:

- /chrisbanes-skills:compose-component-design
- /chrisbanes-skills:compose-state-and-effects

When working on animations in compose use /chrisbanes-skills:compose-animations skill.

When working on compose UI performance use /chrisbanes-skills:compose-performance skill.

When writing or reviewing Jetpack Compose UI for TV, keyboard, desktop, accessibility focus, D-pad
navigation, FocusRequester, focusProperties, key events, or initial focus behavior, use
/chrisbanes-skills:compose-focus-navigation skill.
